# Web UI 美化（设计机构质感 · 反 AI 模板）

在「保留现有代码、只做加法」的前提下，把网站打磨得更酷、更有辨识度，同时**坚决避开一眼就被认出是 AI 生成的模板样式**。

## 何时使用

- 用户说「进一步美化」「随你发挥」「怎么酷怎么来」「更吸引眼球」
- 需要视觉精修、微交互、动效打磨
- 目标是「设计机构官网」质感，而非「AI 生成的通用官网」

## 核心心法

1. **克制优先，加细节不做大改**：每一轮只加 2~4 处协调的细节，不做推翻式重构。
2. **只做加法，不破坏现有代码/样式**：现有样式一律保留，新样式作为补充叠加。
3. **动效服务于主题**：动效要与站点本身的气质一致（科技站用终端/黑客意象，而非通用炫技）。
4. **随改随验**：改完跑一次构建，确认无报错。

## 反 AI 模板黑名单（务必避免）

- 毛玻璃/玻璃拟态（大块 `backdrop-filter: blur` 面板）
- 渐变发光、霓虹紫 / 蓝紫通用配色
- 千篇一律的居中 Hero + 通用渐变背景
- emoji 滥用、无意义的装饰性图标堆砌
- 一眼「套模板」的卡片阴影 + 圆角 + hover 放大三件套

## 推荐的质感手法（按主题选）

### 终端 / 黑客 / 安全主题
- **打字机效果**：用内联 JS 逐字打印，而非 CSS `ch` 单位动画（后者易截断）。
- **提示符**：`$` / `>` / `_` 光标，等宽字体，制造命令行质感。
- **跑马灯关键词**：短词 + 点分隔（`Web · Pwn · Crypto`），副本数给足（8 份）避免出现空白缺口，悬停可暂停。
- **对角扫描线**：大尺寸伪元素 + `linear-gradient` 斜线 + `transform` 位移，比单调上下扫更有设计感。
- **glitch 文字阴影**：hover 时 RGB 分量的 `text-shadow` 抖动。
- **十字准星卡角**：卡片 hover 时四角浮现 `+` 形角标，安全实验室意象。

### 编辑排版
- **超大出血 Watermark**：首屏背景放超大号站点名，制造杂志式留白。
- **编号 eyebrow**：`01 · Research` 这种等宽编号小节标签，替代通用标题装饰。

### 微交互
- 下划线从左到右描画（`background-image` + `background-size` 过渡）
- 滚动渐入（IntersectionObserver）
- 顶部滚动进度条（`requestAnimationFrame` 节流）

## 技术纪律（每一条都很重要）

- **浅色/深色自适应**：新样式只用现有 CSS 变量（`var(--primary)` 等），不硬编码颜色。
- **无障碍**：所有动效都要写 `@media (prefers-reduced-motion: reduce)` 兜底关闭。
- **i18n 同步**：中/英双版本要同步改，不能只改一边。
- **防 FOUC**：滚动渐入这类「默认隐藏」的效果，要在 `<head>` 提前注入 `.js` 类，避免内容先闪后隐。
- **不可靠的 CSS 技巧用 JS 替代**：`ch` 单位测量跨字体不一致 → 改用逐字 JS 打印。

## 常见坑与修复对照

| 症状 | 根因 | 修复 |
|------|------|------|
| 打字动画截断（只显示一半字符串） | `ch` 单位不一致 + flex 压缩 | 改内联 JS 逐字打印，并给元素加 `flex-shrink: 0` |
| 跑马灯末端留大段空白 | 副本数太少、轨道宽度不够 | 关键词副本加到 8 份，调整间距/时长 |
| 动效单调（上下扫） | 只动 `top`/`left` 属性 | 改用 `transform` 位移 + 对角线方向 |

## 流程建议

1. 先读现有页面与全局样式，确认可用变量和既有手法。
2. 挑 2~4 处协调的细节下手，不要贪多。
3. 中英双版本同步。
4. 跑构建验证，再向用户简述「改了什么 + 为什么」，并预留可回退/可微调的空间。
