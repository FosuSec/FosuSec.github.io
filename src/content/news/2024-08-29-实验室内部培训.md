**2024年8月20日**，佛山大学网络安全实验室**马老师**和**宇杰师兄**开展了针对基础薄弱学员的内部培训，旨在提升实验室成员对 SQL 注入和一些热门漏洞的了解。

---

## 01 培训记录

### 01. 主要内容

1. SQL 注入原理技巧
2. 报错注入
3. MySQL 简单使用
4. Linux 提权漏洞 **CVE-2024-1086** 演示
5. **Log4j2** 原理和简单复现
6. **MS17-010** 复现

### 02. 培训情况

![](/img/2024-08-20-1.png)
![](/img/2024-08-20-2.png)

- **SQL 注入漏洞原理讲解**：通过 PHP 代码示例讲解 SQL 注入的产生原因，演示了如何通过注入 `'admin'#` 绕过密码验证
- **SQLi-LABS 靶场实操**：演示了报错注入（Error Based String），通过 `union select` 查询 `information_schema` 获取数据库名（challenges, dvwa, mysql, performance_schema, security）
- **Obsidian 笔记展示**：包含 information_schema 结构说明（schemata、tables、columns 表）、order by、union select 等前置知识

### 03. 培训总结

马老师讲述 SQL 的基础知识并且明确了 SQL 的学习方向，宇杰师兄则从多个方面讲述了 SQL 注入的应用，并且一一演示。该培训比较系统，且对零基础学生友好，**建议反复观看**。
